# 🐛 Troubleshooting

Soluciones a problemas comunes al usar Jurassic Docs.

## 🚨 Problemas frecuentes

### Build falla con "require.resolveWeak is not a function"

**❌ Error:**
```
TypeError: require.resolveWeak is not a function
```

**✅ Solución:**
Este es un problema conocido con Docusaurus 3.x. Usa Docusaurus 2.x:

```json title="package.json"
{
  "dependencies": {
    "@docusaurus/core": "^2.4.3",
    "@docusaurus/preset-classic": "^2.4.3",
    "@mdx-js/react": "^1.6.22"
  }
}
```

### No se detectan proyectos

**❌ Síntoma:**
```
[JurassicDocs] Proyectos detectados: []
```

**🔍 Diagnóstico:**
```bash
node ./scripts/loadProjects.js
```

**✅ Posibles causas:**

1. **Rutas incorrectas en JSON:**
   ```json
   // ❌ Mal
   { "projects": ["./mi-proyecto"] }
   
   // ✅ Bien  
   { "projects": ["../mi-proyecto"] }
   ```

2. **Estructura de carpetas incorrecta:**
   ```
   mi-proyecto/
   ├── docs/           # ❌ Mal
   └── .docusaurus/    # ✅ Debe estar aquí
       └── docs/
   ```

3. **Permisos de archivo:**
   ```bash
   chmod -R 755 ../mi-proyecto
   ```

### Proyecto no aparece en navbar

**🔍 Verificar:**

1. **El proyecto se detecta:**
   ```bash
   node ./scripts/loadProjects.js
   ```

2. **Datos de runtime generados:**
   ```bash
   cat .jurassicRuntime/projectsData.json
   ```

3. **Reiniciar servidor:**
   ```bash
   pnpm start
   ```

### Error "Module not found: @mdx-js/react"

**✅ Solución:**
```bash
pnpm add @mdx-js/react@^1.6.22
```

### Sidebar no se genera automáticamente

**🔍 Verificar `sidebars.js`:**
```javascript
// ✅ Correcto
module.exports = {
  autogenerated: [{ type: 'autogenerated', dirName: '.' }]
};
```

### CSS/Estilos no cargan

**✅ Verificar estructura:**
```
src/
└── css/
    └── custom.css    # ← Debe existir
```

**✅ Configurar en `docusaurus.config.js`:**
```javascript
theme: {
  customCss: require.resolve('./src/css/custom.css'),
}
```

## 🔧 Comandos de diagnóstico

### Verificar configuración completa

```bash
# Ver proyectos configurados
cat jurassic.projects.json

# Probar detección
node ./scripts/loadProjects.js

# Ver datos de runtime
node ./scripts/generateRuntime.js
cat .jurassicRuntime/projectsData.json

# Verificar estructura
find . -name ".docusaurus" -type d
```

### Limpiar caché

```bash
# Limpiar build
rm -rf build/
rm -rf .docusaurus/

# Limpiar deps
rm -rf node_modules/
pnpm install

# Limpiar runtime
rm -rf .jurassicRuntime/
```

## 🚀 Problemas de rendimiento

### Build muy lento

**🔧 Optimizaciones:**

1. **Excluir archivos innecesarios:**
   ```javascript
   // En docusaurus.config.js
   include: ['**/*.md', '**/*.mdx'],
   exclude: ['**/node_modules/**', '**/build/**']
   ```

2. **Usar rutas absolutas:**
   ```javascript
   // Más rápido
   path: '/absolute/path/to/docs'
   
   // Más lento  
   path: '../../../relative/path'
   ```

### Demasiados proyectos

Si tienes muchos proyectos, considera:

1. **Dividir por categorías:**
   ```json
   {
     "projects": [
       "../frontend-projects/app1",
       "../backend-projects/api1"
     ]
   }
   ```

2. **Usar instancias separadas:**
   - `frontend-docs/` 
   - `backend-docs/`
   - `mobile-docs/`

## 🐞 Debug mode

### Habilitar logs detallados

```javascript title="docusaurus.config.js"
const dynamicProjects = loadProjects();
console.log('[DEBUG] Proyectos cargados:', dynamicProjects);
console.log('[DEBUG] Plugins generados:', docsPlugins.length);
```

### Variables de entorno

```bash
# Más información de Docusaurus
DEBUG=true pnpm start

# Node.js debug
NODE_ENV=development pnpm start
```

## 🔄 Problemas de hot reload

### Cambios no se reflejan

**✅ Soluciones:**

1. **Reiniciar servidor completo:**
   ```bash
   # Ctrl+C para parar
   pnpm start
   ```

2. **Regenerar runtime:**
   ```bash
   node ./scripts/generateRuntime.js
   pnpm start
   ```

3. **Verificar watch de archivos:**
   - Cambios en `jurassic.projects.json` requieren restart
   - Cambios en archivos `.md` se detectan automáticamente

### Reportar problemas

Incluye en tu reporte:

1. 🖥️ **Sistema:** OS, Node.js, pnpm versions
2. 📋 **Config:** `jurassic.projects.json` y `package.json`
3. 🔍 **Output:** Resultado de `node ./scripts/loadProjects.js`
4. 📝 **Error:** Mensaje completo de error
5. 🗂️ **Estructura:** Layout de carpetas de tus proyectos
